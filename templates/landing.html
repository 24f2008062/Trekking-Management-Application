02 // APPLICATION BUILD

HOW THE APPLICATION IS BUILT

MODERN FULL-STACK ARCHITECTURE • ROBUST & SECURE

01 // BACKEND ENGINE
PYTHON & FLASK

Modular MVC backend built with Flask and SQLAlchemy ORM, managing database relationships, role-based route protection, and dynamic Jinja2 template rendering.

FLASK • SQLALCHEMY • SQLITE / POSTGRES
02 // RELATIONAL DATABASE
SQLITE & SQLALCHEMY

Structured relational database models with foreign key integrity, managing users, expedition catalogs, role permissions, and confirmed booking records.

SQLITE 3 • SQLALCHEMY ORM • RELATIONAL
03 // 3D GRAPHICS
THREE.JS WEBGL

Hardware-accelerated 3D vector background and interactive topographic elevation models responding smoothly to scroll and mouse navigation.

THREE.JS • GPU ACCELERATED • 60+ FPS
04 // DESIGN & SECURITY
BAUHAUS UI & SECURITY

Clean Bauhaus Weimar aesthetic with crisp typography and high contrast, secured with Bcrypt password hashing and rate-limiting defenses.

BCRYPT • CSP ENFORCED • LIGHT / DARK
